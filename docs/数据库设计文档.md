## 1. 概述

- 数据库版本管理：Alembic；
- 开发环境：SQLite 3（WAL 模式）；生产环境：PostgreSQL 15+；
- 时间规范：时间戳统一存储 **UTC（ISO8601）**，展示层转为 Asia/Shanghai；交易日期字段使用 `YYYY-MM-DD`（Asia/Shanghai 交易日）；
- 精度：SQLite 使用 `REAL`；PostgreSQL 价格/金额使用 `NUMERIC(18,4)`；
- 主键策略：业务主键（如股票代码）用 `TEXT`；其余表用自增 `INTEGER` / `BIGSERIAL`。

## 3. 表清单

|------|------|----------------|
| stocks | 股票基础信息 | PK(code) |

| logs | 运行日志 | (ts)、(level) |

## 4. 建表 DDL（SQLite）

```sql
-- stock-agent v0.1 数据库 DDL（SQLite 兼容）
PRAGMA journal_mode = WAL;

CREATE TABLE IF NOT EXISTS stocks (
    code       TEXT PRIMARY KEY,
    name       TEXT NOT NULL,
    industry   TEXT,
    market     TEXT NOT NULL DEFAULT 'SSE',
    enabled    INTEGER NOT NULL DEFAULT 1,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS daily_quotes (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    code      TEXT NOT NULL,
    date      TEXT NOT NULL,
    open      REAL,
    high      REAL,
    low       REAL,
    close     REAL,
    pre_close REAL,
    volume    INTEGER,
    amount    REAL,
    turn_rate REAL,
    UNIQUE (code, date),
    FOREIGN KEY (code) REFERENCES stocks(code)
);

CREATE TABLE IF NOT EXISTS financials (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    code        TEXT NOT NULL,
    report_date TEXT NOT NULL,
    revenue     REAL,
    net_profit  REAL,
    eps         REAL,
    roe         REAL,
    UNIQUE (code, report_date),
    FOREIGN KEY (code) REFERENCES stocks(code)
);

CREATE TABLE IF NOT EXISTS strategies (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL,
    version     TEXT NOT NULL DEFAULT '0.1.0',
    class_name  TEXT NOT NULL,
    params_json TEXT,
    enabled     INTEGER NOT NULL DEFAULT 1,
    created_at  TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS strategy_runs (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    strategy_id     INTEGER NOT NULL,
    run_date        TEXT NOT NULL,
    status          TEXT NOT NULL DEFAULT 'running',
    started_at      TEXT,
    finished_at     TEXT,
    candidates_json TEXT,
    error           TEXT,
    FOREIGN KEY (strategy_id) REFERENCES strategies(id)
);

CREATE TABLE IF NOT EXISTS trade_plans (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    plan_date    TEXT NOT NULL UNIQUE,
    status       TEXT NOT NULL DEFAULT 'draft',
    total_budget REAL,
    created_at   TEXT NOT NULL DEFAULT (datetime('now')),
    note         TEXT
);

CREATE TABLE IF NOT EXISTS trade_plan_items (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    plan_id   INTEGER NOT NULL,
    code      TEXT NOT NULL,
    side      TEXT NOT NULL CHECK (side IN ('buy', 'sell')),
    quantity  INTEGER NOT NULL,
    price_min REAL,
    price_max REAL,
    expire_at TEXT,
    status    TEXT NOT NULL DEFAULT 'pending',
    reason    TEXT,
    FOREIGN KEY (plan_id) REFERENCES trade_plans(id),
    FOREIGN KEY (code) REFERENCES stocks(code)
);

CREATE TABLE IF NOT EXISTS orders (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    client_request_id TEXT UNIQUE,
    item_id    INTEGER NOT NULL,
    order_no   TEXT,
    code       TEXT NOT NULL,
    side       TEXT NOT NULL,
    quantity   INTEGER NOT NULL,
    price      REAL,
    status     TEXT NOT NULL DEFAULT 'pending',
    error      TEXT,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (item_id) REFERENCES trade_plan_items(id)
);

CREATE TABLE IF NOT EXISTS trades (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    client_request_id TEXT NOT NULL UNIQUE,
    order_id   INTEGER NOT NULL,
    code       TEXT NOT NULL,
    side       TEXT NOT NULL,
    quantity   INTEGER NOT NULL,
    price      REAL NOT NULL,
    amount     REAL,
    commission REAL,
    traded_at  TEXT NOT NULL,
    FOREIGN KEY (order_id) REFERENCES orders(id)
);

CREATE TABLE IF NOT EXISTS account_snapshots (
    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    snapshot_date  TEXT NOT NULL UNIQUE,
    total_asset    REAL,
    available_cash REAL,
    market_value   REAL,
    positions_json TEXT,
    created_at     TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS api_keys (
    key_hash   TEXT PRIMARY KEY,
    name       TEXT NOT NULL,
    enabled    INTEGER NOT NULL DEFAULT 1,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    expires_at TEXT
);

CREATE TABLE IF NOT EXISTS logs (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    ts         TEXT NOT NULL,
    level      TEXT NOT NULL,
    module     TEXT,
    message    TEXT NOT NULL,
    extra_json TEXT
);

CREATE TABLE IF NOT EXISTS daily_reports (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    report_date  TEXT NOT NULL UNIQUE,
    summary_json TEXT,
    created_at   TEXT NOT NULL DEFAULT (datetime('now'))
);
```

## 5. 索引设计

```sql
CREATE INDEX IF NOT EXISTS idx_strategy_runs_strategy_date
    ON strategy_runs(strategy_id, run_date);
CREATE INDEX IF NOT EXISTS idx_trade_plan_items_plan
    ON trade_plan_items(plan_id);
CREATE INDEX IF NOT EXISTS idx_trade_plan_items_code
    ON trade_plan_items(code);
CREATE INDEX IF NOT EXISTS idx_orders_item
    ON orders(item_id);
CREATE INDEX IF NOT EXISTS idx_orders_status
    ON orders(status);
CREATE INDEX IF NOT EXISTS idx_trades_order
    ON trades(order_id);
CREATE INDEX IF NOT EXISTS idx_trades_traded_at
    ON trades(traded_at);
CREATE INDEX IF NOT EXISTS idx_logs_ts
    ON logs(ts);
CREATE INDEX IF NOT EXISTS idx_logs_level
    ON logs(level);
```

说明：
- `daily_quotes(code, date)` 已由 UNIQUE 约束覆盖，支持按股票+日期区间查询；
- 高频查询路径：`trade_plan_items(plan_id)`、`orders(item_id)`、`trades(order_id)`。

## 6. PostgreSQL 适配

| SQLite | PostgreSQL |
|--------|------------|
| `INTEGER PRIMARY KEY AUTOINCREMENT` | `BIGSERIAL PRIMARY KEY` |
| `TEXT` | `TEXT` / `VARCHAR(n)` |
| `REAL` | `NUMERIC(18,4)`（价格/金额） |
| `INTEGER`（布尔） | `BOOLEAN` |
| `datetime('now')` | `now()` |
| `CHECK` 与 `FOREIGN KEY` 需手动开启 | 默认启用 |

建议生产环境：
- 日期字段使用 `DATE` 类型；
- 时间戳使用 `TIMESTAMPTZ`；
- 价格/金额使用 `NUMERIC` 避免浮点误差。

| 数据 | 保留期 | 处理 |
|------|--------|------|
| daily_quotes / financials | 3 年 | 归档到冷存储 |
| orders / trades / daily_reports | 永久 | 只增不改 |
| logs | 180 天 | 定期清理 |
| strategy_runs（candidates_json） | 1 年 | 定期清理 |

## 8. 迁移策略

1. 修改 `backend/app/models/` 中 ORM 模型；
2. 生成迁移：`alembic revision --autogenerate -m "描述"`；
3. 人工审查迁移脚本（重点：默认值、索引、存量数据迁移）；
4. 应用：`alembic upgrade head`；
5. CI 中执行 `alembic upgrade head && pytest`。
